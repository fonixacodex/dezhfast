Build with DEZH

A modular FastAPI framework with an Artisan-style CLI, structured exceptions, request tracing, and multi-database support.

Installation

Requirements

  • Python 3.11+ (3.12 recommended)
  • Redis (optional, for background jobs)
  • Docker (optional)

Install

bash 
pip install dezh

Quickstart

1. Create a project

bash 
dezh new myapp
cd myapp

2. Install and configure

bash 
py -m venv .venv
source .venv/bin/activate      # Windows: .\.venv\Scripts\Activate.ps1

pip install -e ".[dev]"
cp .env.example .env

3. Run

bash 
dezh serve run

Then open:

  • http://127.0.0.1:8000/docs — Swagger UI
  • http://127.0.0.1:8000/health — liveness
  • http://127.0.0.1:8000/ready — readiness (with DB check)

Project Structure

tree 
myapp/
├── app/                    # your application code
│   ├── core/               # config, security, exceptions, middleware, logging
│   ├── api/                # shared HTTP layer
│   ├── database/           # engine, session, base
│   ├── modules/            # your domain modules
│   └── main.py
├── framework/              # reusable core (container, lifecycle, module)
├── cli/                    # Artisan-style commands
├── resources/              # templates + static
├── storage/                # db, logs, uploads
├── tests/
├── pyproject.toml
├── Dockerfile
├── docker-compose.yml
└── .env.example

Modules

Every module extends BaseModule and implements two methods:

app/modules/posts/__init__.py 
from framework.module import BaseModule


class PostsModule(BaseModule):
    name = "posts"

    def register_di(self, container) -> None:
        pass

    def register_routes(self, app) -> None:
        from .router import router
        app.include_router(router, prefix="/posts", tags=["posts"])

Register it in main.py:

app/main.py 
from app.modules.posts import PostsModule

factory.register_module(PostsModule())

DI Container

python 
# bind — new instance every resolve
container.bind("email_sender", lambda c: EmailSender())

# singleton — one instance, cached
container.singleton("db", lambda c: create_engine(...))

# instance — ready-made object
container.instance("config", settings)

# resolve
service = container.resolve("posts_service")

Supports SQLite, PostgreSQL, and MySQL via DB_CONNECTION.

DB_USERNAME=dezh

DB_DATABASE_NAME=dezh

Auto-create tables

In main.py, tables are created automatically in dev/staging:

app/main.py 
async def _auto_create_tables() -> None:
    if settings.APP_ENV == "prod":
        return
    import_all_models()
    async with engine.begin() as conn:
        await conn.run_sync(Base.metadata.create_all)

factory.lifecycle.add_startup(_auto_create_tables)

Exception Handling

12 ready-made exception classes:

python 
from app.core.exceptions import (
    BadRequestError,        # 400
    UnauthorizedError,      # 401
    InvalidTokenError,      # 401
    ForbiddenError,         # 403
    AdminRequiredError,     # 403
    NotFoundError,          # 404
    ConflictError,          # 409
    ValidationError,        # 422
    RateLimitError,         # 429
    InternalError,          # 500
)

Every error is returned in a unified format:

json 
{
  "error": {
    "code": "not_found",
    "message": "Post 42 not found",
    "details": null,
    "request_id": "a1b2c3d4"
  }
}

Troubleshooting

ModuleNotFoundError: No module named 'app'

bash 
pip install -e .

unable to open database file

The storage/db/ folder doesn't exist. Dezh creates it automatically in _auto_create_tables. If it still fails:

bash 
mkdir -p storage/db

ERR_CONNECTION_REFUSED

The server is not running. Start it with dezh serve run and keep the terminal open.

reload crashes on Python 3.14 (Windows)

Known bug with multiprocessing.spawn. Use:

bash 
dezh serve run --no-reload
